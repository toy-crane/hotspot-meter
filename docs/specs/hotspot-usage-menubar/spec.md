# 핫스팟 사용량 메뉴바 앱

승인된 화면: [prototype.html](prototype.html)

## 배경

강의처럼 외부 인터넷을 쓸 수 없는 며칠 동안, iPhone 핫스팟의 한정된 데이터로 개발을 이어 가야 한다. 이 기간에 지금까지 얼마나 썼는지 Mac에서 바로 확인하면서 사용량을 조절하고 싶다. 핫스팟 한도는 그때그때 달라지므로, 앱은 한도가 아니라 현재까지 쓴 양을 보여 준다.

## 사용자에게 보이는 결과

- 메뉴바에 핫스팟 아이콘과 누적 사용량(예: `1.88 GB`)이 항상 보인다.
- 메뉴바 항목을 누르면 작은 창이 열리고, 위에서부터 다음이 보인다.
  - 집계 시작 시각: `10월 27일 오후 9:14부터`
  - 누적 사용량(가장 크게)과 집계 상태 표시: 핫스팟에 연결되어 있으면 초록색 `집계 중`, 아니면 회색 `핫스팟 아님`
  - `초기화`, `종료` 버튼
- 강의 기간을 시작할 때 `초기화`를 누르면 누적이 0이 되고, 시작 시각이 그 순간으로 바뀐다.

## 승인된 범위

- 메뉴바 항목: 아이콘과 누적 사용량. 핫스팟이 아닐 때는 사선이 그어진 아이콘과 흐린 숫자로 표시하고, 누적값은 그대로 보인다.
- 메뉴바 창: 시작 시각, 누적 사용량, 집계 상태, `초기화`, `종료`
- 초기화 확인 창
  - 제목 `사용량을 초기화할까요?`
  - 설명 `{누적 사용량} 기록이 사라집니다.`
  - 버튼 `초기화`(빨간색이 아닌 일반 버튼), `취소`(기본 버튼)
  - 모양은 macOS 기본 확인 창을 따른다. 프로토타입의 HTML 확인 창 모양은 기준이 아니며, 문구와 버튼 구성만 기준이다.
- `종료`를 누르면 앱이 끝나고 메뉴바 항목이 사라진다.

## 확인 기준

- iPhone USB 테더링이나 Wi-Fi 개인용 핫스팟에 연결되어 있으면 상태가 `집계 중`이고, 데이터를 쓰는 만큼 누적 사용량이 늘어난다.
- 일반 Wi-Fi나 유선 네트워크에서는 상태가 `핫스팟 아님`이고, 그 네트워크로 쓴 데이터는 누적에 더해지지 않는다.
- 핫스팟 연결이 끊겼다가 다시 연결되어도(USB 케이블을 뺐다 꽂는 경우 포함) 누적은 0으로 돌아가지 않고 이어서 쌓인다.
- 앱을 종료했다가 다시 실행하거나 Mac을 재시동해도 누적 사용량과 시작 시각이 유지된다.
- 4 GB를 넘게 써도 누적이 0 근처로 돌아가거나 줄어들지 않는다.
- `초기화` → `취소`, 또는 확인 창에서 Esc를 누르면 아무것도 바뀌지 않는다.
- `초기화` → 확인 창의 `초기화`를 누르면 누적이 0이 되고, 시작 시각이 누른 시각으로 바뀐다.
- 확인 창이 떠 있을 때 Enter를 누르면 `취소`로 동작한다.
- 메뉴바 숫자와 창의 숫자가 항상 같은 값을 보여 준다.

## 정해진 제약과 이유

- **한도를 보여 주지 않는다.** 핫스팟 한도는 상황마다 바뀐다. 사용자가 필요로 하는 건 지금까지 쓴 양이다.
- **누적 하나만 보여 준다.** 연결 단위 사용량, 받은 양과 보낸 양의 구분, 연결 방식(USB/Wi-Fi), 경과 시간은 검토 과정에서 뺐다. 요금은 합계로만 깎이고, 사용자가 남은 양을 판단하는 데는 누적과 시작 시각이면 충분하다.
- **시작 시각은 날짜와 시각을 함께 보여 준다.** 처음에는 날짜만 보여 주고 시각은 툴팁으로 두었지만, 실제로 써 보니 초기화 직후 언제부터 센 값인지 알 수 없었다. 같은 날 여러 번 초기화해도 구분할 수 있도록 시각까지 바로 보여 준다.
- **초기화는 확인을 거친다.** 강의 도중 실수로 누르면 기록을 되돌릴 수 없다.
- **핫스팟 판별에 위치 권한을 요구하지 않는다.** USB 테더링에는 SSID가 없으므로 Wi-Fi 이름으로 판별할 수 없다. macOS가 비싼(expensive) 네트워크로 표시한 연결을 핫스팟으로 본다.
- **외부 라이브러리를 쓰지 않는다.** 개발 자체를 핫스팟 데이터로 해야 한다.

## 가정 (바꿀 수 있음)

- 로그인할 때 앱이 자동으로 실행된다. 앱이 꺼져 있는 동안 쓴 데이터는 셀 수 없으므로, 재시동 후 실행을 잊는 경우를 막기 위한 기본값이다.
- 용량 단위는 10진수다(1 GB = 1,000,000,000 바이트). 통신사 표기 방식에 가깝다.
- 앱을 처음 실행하면 그 순간부터 집계를 시작한다.
- 앱 화면은 macOS 시스템 외관(라이트/다크)을 따른다. 프로토타입은 라이트 모드만 보여 준다.

## 범위 밖과 그 이유

- 한도 설정, 남은 양 계산, 한도 초과 알림: 한도가 매번 달라서 지금은 필요 없다.
- 프로세스별 사용량: 무엇이 데이터를 썼는지보다 얼마나 썼는지가 목적이다.
- 사용 기록 그래프, 일별 내역: 강의 기간 하나의 합계만 필요하다.
- App Store 배포와 공증: 사용자 본인의 Mac에서만 쓴다.

## 미룬 것

- 사용 속도(시간당 사용량) 표시: 검토 중 제안했지만 화면을 단순하게 유지하기 위해 뺐다. 필요해지면 다시 다룬다.

## 위험

- 앱이 실행 중일 때만 집계된다. 앱을 종료한 동안 쓴 데이터는 누적에 들어가지 않는다.
- 통신사 집계와 값이 다를 수 있다. iPhone 자체가 쓴 데이터는 포함되지 않고, 통신사의 계산 방식이 다를 수 있다.
- macOS가 핫스팟을 비싼 네트워크로 표시하지 않는 환경(일부 Android 테더링, 외부 공유기 등)에서는 집계되지 않을 수 있다.
